## 🚀 Proyecto destacado

### [workspace-tenant-auditor](https://github.com/arulcancela/workspace-tenant-auditor)

> Audita la configuración de seguridad de un tenant de Google Workspace y genera
> un informe ejecutivo (HTML/PDF/JSON) con hallazgos priorizados por severidad.

[![CI](https://github.com/arulcancela/workspace-tenant-auditor/actions/workflows/ci.yml/badge.svg)](https://github.com/arulcancela/workspace-tenant-auditor/actions)
![Python](https://img.shields.io/badge/python-3.11%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

**El problema:** en empresas con cientos de empleados en Workspace, la seguridad
se degrada sin que nadie lo note — usuarios sin doble verificación, cuentas de
ex-empleados activas, Drive abierto, apps OAuth con permisos excesivos. Revisarlo
a mano no escala.

**La solución:** un comando que ejecuta **12 comprobaciones**, prioriza por
severidad y entrega un informe listo para dirección o para un cliente.

| | |
|---|---|
| **Stack** | Python 3.11+ · Admin SDK · Reports API · Jinja2 · WeasyPrint · Typer |
| **Autenticación** | Service Account + Domain-Wide Delegation (solo lectura) |
| **Calidad** | 60+ tests · 78% cobertura · CI con GitHub Actions · Docker |
| **Extras** | Modo demo sin credenciales · informes HTML/PDF/JSON · CLI completa |
